# 测试用例自动生成Agent README
## 项目简介
基于五层独立Agent模块化架构 + 大模型能力开发的测试用例自动生成工具，支持PRD文档解析、多轮对话生成，解决人工编写用例效率低、格式不统一、超时等痛点，适配测试日常工作场景，可直接用于实战，也可作为求职展示项目。

## 核心功能
1.  **PRD文档智能解析**：自动读取`.docx`格式产品需求文档，精准拆分功能点、业务规则等6大类核心内容，无需手动整理。
2.  **五层Agent流水线处理**：分工明确、完全解耦，可独立修改调整，不影响整体功能。
3.  **多轮对话支持**：手动输入需求可连续生成多组用例，无需重复启动程序，操作便捷。
4.  **强容错优化**：自动修复破损JSON、补齐缺失字段、去重编号，避免字段冗余错乱。
5.  **结果持久化**：生成的用例自动保存为JSON文件，可直接导入测试平台使用。

## 运行使用方式
### 1. 启动项目
```bash
python main.py
```

### 2. 主菜单操作
启动后进入主菜单，支持3种操作：
- 输入`1`：手动输入业务需求（支持多轮对话）
  1.  多行输入需求，连续两次回车提交
  2.  生成用例后，可直接输入新需求，无需重启程序
  3.  输入`q`可退出手动输入模式，返回主菜单
- 输入`2`：导入docx格式PRD文档
  1.  输入文档完整路径（例：D:/prd/需求文档.docx）
  2.  程序自动解析、生成用例，完成后返回主菜单
- 输入`q`：退出整个程序

### 3. 模式详情
#### 模式1：手动输入需求（多轮对话）
1.  主菜单输入`1`，进入手动输入模式
2.  多行输入业务需求，连续两次回车提交
3.  程序自动生成用例，完成后停留手动输入界面，可继续输入新需求
4.  输入`q`，返回主菜单

#### 模式2：导入PRD文档
1.  主菜单输入`2`，输入docx文件完整路径
2.  程序自动解析文档、提取需求、生成用例
3.  生成完成后返回主菜单，可继续操作

### 4. 通用执行流程
1.  解析需求（手动输入/PRD文档）
2.  提取核心功能点，规划测试场景
3.  生成标准化测试用例
4.  本地优化（去重、补全字段、格式统一）
5.  自动保存为`final_test_cases.json`文件
6.  控制台打印结果，支持直接复制使用

## 项目核心优势
1.  架构规范：五层Agent完全解耦，修改单个模块不影响整体，符合企业级工程标准。
2.  高效便捷：多轮对话无需重复启动程序，PRD解析无需手动整理，大幅提升测试效率。
3.  容错性强：破损JSON修复、字段补齐、中英文统一，避免用例错乱。
4.  实战适配：贴合测试日常工作流程，可直接用于职场提效，也可作为求职实战项目。
5.  易扩展：支持替换大模型、新增Excel导出、对接测试管理平台，低门槛二次开发。

## 常见问题解决
1.  中英字段重复：内置字段映射，自动统一为中文标准字段，剔除冗余英文字段。
2.  大模型超时：优先本地处理，减少模型调用，搭配重试机制，避免阻塞。
3.  用例数量异常：内置阈值控制，不足自动补充，过多自动截断，保证用例质量。
4.  无法多轮对话：确认替换最新版`main.py`，重启程序后重新进入手动输入模式即可。
